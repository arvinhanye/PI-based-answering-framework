## 1. 准备环境

目前只在 **macOS** 上完整验证过。Windows、Linux 可以尝试，但遇到问题可能需要自己排查。

| 需要 | 检查方法 | 没有时 |
| --- | --- | --- |
| Node.js 24 或更新版本 | 终端运行 `node -v`，显示 `v24` 或更高 | 到 [nodejs.org](https://nodejs.org) 下载 LTS 版安装 |
| Git | 运行 `git --version` | macOS 运行 `xcode-select --install` |
| 推荐的终端 | — | **Warp**、iTerm2、Ghostty、kitty、WezTerm 能直接显示题图；系统自带的“终端”也能用，只是题图要另外打开 |
| DeepSeek API key（可选） | — | 见 [第 5 节](#5-问-deepseek)。没有也能刷题，只是不能问 AI |

## 2. 安装

在终端里逐行运行：

```sh
npm install -g --ignore-scripts @earendil-works/pi-coding-agent@0.87.1
```

```sh
git clone https://github.com/arvinhanye/PI-based-answering-framework.git
```

```sh
cd PI-based-answering-framework/pi-study
```

```sh
npm ci
```

```sh
npm run build
```

```sh
cd ..
```

```sh
pi install --local ./pi-study
```

说明：

- 第一行安装 Pi。本工具按 Pi 0.87.1 测试，请装这个版本。
- 最后一行把本工具注册到这个仓库目录。**以后都要在 `PI-based-answering-framework` 目录里启动 `pi`**，在别的目录启动看不到 `/study`。
- 安装成功时，最后一行会输出 `Installed ./pi-study`。

## 3. 导入题库

题库来自第三方资料，**不放在公开仓库里**。请向组长要题库数据包，它是一个 `.zip` 文件（约 110 MB）。拿到后，在仓库目录下运行下面两条命令，把路径换成你实际保存数据包的位置。

先预览：

```sh
node pi-study/dist/cli/index.js restore ~/Downloads/pi-study-题库.zip --to "$HOME/Library/Application Support/pi-study/spaces/team"
```

这一步会打印一长串文件清单和校验信息，只做检查，不写入任何数据。没有报错的话，在同一条命令末尾加上 `--yes` 真正导入：

```sh
node pi-study/dist/cli/index.js restore ~/Downloads/pi-study-题库.zip --to "$HOME/Library/Application Support/pi-study/spaces/team" --yes
```

看到 `"restored"` 就成功了，程序会自动切换到这份题库。可以运行下面的命令确认，应当显示 `"totalQuestions": 2596`：

```sh
node pi-study/dist/cli/index.js stats
```

注意：

- 数据包里有原始题库文件，**只在组内传，不要上传到公开的地方**。
- `--to` 指定的目录必须是一个还不存在的新目录。
- 以后组长发了新版数据包，用同样的方法导入到另一个新目录（例如把 `team` 改成 `team2`）。程序会切换到新目录，旧目录里的作答记录不会被删除，但新目录里看不到旧记录。

## 4. 开始刷题

在仓库目录启动 Pi：

```sh
pi
```

在 Pi 的输入框里输入 `/study` 回车。第一次会问比赛日期，可以直接按 Esc 跳过，以后在设置里补。之后就能看到第一道题。

### 作答

| 题型 | 怎么输入 | 例子 |
| --- | --- | --- |
| 单选 | 一个选项字母，大小写都行 | `b`、`选B`、`答案是B` |
| 多选 | 几个字母连写，或用空格、逗号隔开 | `AC`、`a c`、`A,C` |
| 判断 | 对 / 错 | `对`、`错`、`√`、`×`、`T`、`F`，也可以用 `A`、`B` |
| 填空 | 以 `=` 开头，多个空用 `\|` 隔开 | `=display ip routing-table`、`=第一空\|第二空` |

- 回车后立即显示对错、正确答案和解析，**没有确认框**。
- **没把握**时在答案后加问号，例如 `B?`。照常判分，但这题第二天会再出现。
- **手滑了**：在进入下一题之前输入 `/study undo`，撤销后重新作答。进入下一题后就不能撤销上一题了。
- 输入不合法时不会判分，只会提示原因，例如单选题输入了 `AB`，或者输入了题目里没有的选项字母。
- 卡片上注明“本题不计分”的题（例如原题缺图、原题没给答案），照样可以练，只是不计入成绩。

### 下一题、退出

| 输入 | 作用 |
| --- | --- |
| `n` 或 `下` | 下一题。还没作答时会跳过这题 |
| `Ctrl+N` | 同 `n`，可选快捷键 |
| `图` | 打开当前题的题图，见 [第 7 节](#7-题图) |
| `/study exit` | 退出学习，回到普通 Pi 对话。所有作答已经保存 |
| `/study` | 下次进来，接着上次的题继续 |

输入框下方有一行常驻提示，显示可用的操作、本轮答对答错的题数，以及本月 AI 费用。

### 选题

| 输入 | 出什么题 |
| --- | --- |
| `/study` | 接着上次。没有进行中的一轮时，从全库开始 |
| `/study 1500`、`/study 省赛`、`/study pdf` | 只出这一份题库的题，开新一轮 |
| `/study 错题` | 只出答错过、之后还没独立答对的题。可以组合，例如 `/study 省赛 错题` |
| 在后面加 `随机` | 新题打乱顺序，例如 `/study 1500 随机` |

默认先出到期的复习题和错题，每 4 道复习题插 1 道新题。新题按原题号顺序出，三份题库按 1500 题 → 省赛 → PDF 依次做下去。

## 5. 问 DeepSeek

### 配置（每人一次）

1. 到 [DeepSeek 开放平台](https://platform.deepseek.com) 注册，创建一个 API key，并少量充值。**每人用自己的 key，不要共用，也不要发到群里。**
2. 在 Pi 里输入 `/login`，选择 DeepSeek，粘贴 key。key 保存在你本机 Pi 的配置里，不会进入仓库。

没有配置 key 时，提问会得到一句配置提示，刷题完全不受影响。

### 怎么问

学习时，**凡是不符合作答格式的文字，都会作为提问发给 DeepSeek**，例如 `B为什么不对`、`什么是 CAPWAP`、`给我讲讲这题的考点`。

- 程序会自动带上当前题目、选项和题图；已经作答的话，还会带上你的答案、正确答案和解析。你不需要复制题目。
- 同一道题里可以连续追问。换到下一题后，上一题的对话不会再发给 AI，但仍然留在屏幕上。
- **作答前**也可以问。AI 会尽量引导你思考而不直接说答案；这题会记为“辅助作答”，第二天再出现，也不计入独立作答的正确率。
- AI 回答时不能切题。想打断就按 Esc。
- 想让 AI 想得更深入，输入 `/study think` 打开思考模式，再输入一次关闭。思考模式更慢，也更费钱。
- AI 的讲解仅供参考，不是官方结论。题库答案和 AI 说法冲突时，请以官方文档为准。

### 费用

- 用的是 `deepseek-flash`，一次普通提问通常不到一分钱。
- 默认每月上限 10 元。用到 80% 时会提示一次；用完后不能再提问，刷题照常。
- 输入 `/study budget 20` 可以把上限改成 20 元。
- 这个上限是程序自己记的账，最后一次提问可能会超出几分钱。**真正的硬上限是你 DeepSeek 账户里的余额**，所以建议少量充值。
- 只统计学习时的提问；退出学习后用 Pi 做别的事，不计入这里的额度。

## 6. 复习、错题与设置

**复习规则**：答错、带 `?`、问过 AI 才作答的题，第二天复习；独立答对的题按 1、3、7、14、30 天的间隔复习。设置了比赛日期后，复习间隔不会超过离比赛的剩余天数。

**进度与成绩**：输入 `/study stats`，查看每份题库做到了多少题、独立作答的正确率、辅助作答的成绩、错题数和今天到期的复习题数；设置了比赛日期时还会显示倒计时。查看成绩不会切题，也不会调用 AI。

**设置菜单**：输入 `/study menu`，用方向键选择、回车确认，按 Esc 返回当前题。

| 菜单项 | 作用 |
| --- | --- |
| 切换题库 | 有多个题库时切换 |
| 恢复 · 来源 · 时间 · 已做 N 题 | 回到之前的某一轮 |
| 成绩 | 与 `/study stats` 相同 |
| 预算 | 查看本月 AI 费用、修改上限 |
| 比赛日期 | 格式 `2026-11-13`，留空表示不设 |
| 答对自动下一题 | 打开后，答对直接出下一题，答错照常停下 |

## 7. 题图

带题图的题只在省赛（2 题）和 PDF（160 题）里；1500 题那份没有题图。想马上看效果，可以输入 `/study pdf`，再按几次 `n`，前几题就有带图的。

- **Warp、iTerm2、Ghostty、kitty、WezTerm**：题图直接显示在选项下方。
- **系统自带的“终端”、VS Code 终端、tmux 里**：卡片上会提示“输入 图 打开”。输入 `图`，会用“预览”打开。
- 任何终端里都可以输入 `图`，用“预览”放大查看。

## 9. 常见问题

**输入 `/study` 没反应，或者提示找不到这个命令**
确认是在 `PI-based-answering-framework` 目录里启动的 `pi`。如果仍然不行，在这个目录重新运行 `pi install --local ./pi-study`，然后重启 Pi。如果 Pi 提示项目未受信任，改用：

```sh
pi install --local --approve ./pi-study
```

**提示“尚无题库”，或者 `stats` 显示 0 题**
还没导入题库数据包，见 [第 3 节](#3-导入题库)。

**启动时 Pi 提示 `Ctrl+N` 快捷键冲突**
这是正常的：本工具占用了 Pi 会话选择器里的 `Ctrl+N`，学习时它表示“下一题”。不影响使用。

**`Ctrl+N` 没反应**
个别终端会自己拦截这个组合键。直接输入 `n` 回车即可。

**提问后提示“未配置 DeepSeek”**
在 Pi 里输入 `/login`，选择 DeepSeek 并粘贴 key，见 [第 5 节](#5-问-deepseek)。

**提示“本月 DeepSeek 额度已用完”**
用 `/study budget 20` 提高上限，或者等下个月。刷题不受影响。

**题图不显示，只有一行“输入 图 打开”**
你的终端不支持直接显示图片，输入 `图` 打开即可；想直接显示，可以换用 Warp。

**题目或选项里有错字、乱码**
PDF 题库是从扫描件识别出来的，难免有少量识别错误。请记下卡片标题里的题号（例如 `p12-q45`），告诉组长。

**想在别的电脑上继续刷**
目前需要备份后再在新电脑恢复，见 [pi-study/README.md 的“数据与备份”](../pi-study/README.md#数据与备份)。不确定的话请找组长。

## 10. 数据与隐私

- 你的作答记录只保存在自己电脑上，默认位置是 `~/Library/Application Support/pi-study/`，不会上传。
- DeepSeek key 保存在本机 Pi 的配置里，不在本仓库中，也不会进入备份文件。
- 向 DeepSeek 提问时，当前题目、你的作答和题图会发送给 DeepSeek。
- 仓库是公开的，请不要把题库数据包、截图里的个人信息或 key 提交到仓库。
