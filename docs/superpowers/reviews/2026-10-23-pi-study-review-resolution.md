## 3. 本轮独立事实核验

### 3.1 第一份 DOCX

用标准库 `zipfile`／`ElementTree` 只读 `word/document.xml`，按正文段落顺序和独立题型＋题号建立题块；文本提取保留 `w:br/w:cr/w:tab`，再识别逻辑行首选项。没有修改原件。

| 项目 | 结果 |
| --- | --- |
| 题号 | 连续且唯一 1—1508 |
| 四种题型 | 单选 545、多选 554、判断 400、填空 9；简答 0 |
| 答案／解析 | 每题各 1 个非空段，各 1508 |
| 选项 | 1499 个非空选项段，9 个填空题对应空段；3813 个手动换行，5203 个选项 |
| 续行 | 66 题、109 行；真实样本 57、87、951 |
| 非四选项 | 1099 道单／多选中有 41 道；不能直接视为解析失败 |
| 点号干扰 | 641：X.25；838：RSTP.MSTP；951：NCE-FabriC. |
| 内容内额外 B. | 未发现；此类测试须标人工 fixture |
| 标签 | 安全 125、无线 68、数通 19，无重叠，共 212；1296 无显式考点标签 |

结构核验未发现缺首标签、标签不连续、合并续行后的空选项或单／多选答案字母越界。结构可识别不等于知识答案正确，也不等于应用导入验收已完成。

### 3.2 Pi 0.87.1 输入与发送路径

- [输入类型定义](/usr/local/lib/node_modules/@earendil-works/pi-coding-agent/dist/core/extensions/types.d.ts:721)有 interactive、rpc、extension 三种来源；[会话输入处理](/usr/local/lib/node_modules/@earendil-works/pi-coding-agent/dist/core/agent-session.js:1229)在模型前支持 handled。
- [扩展消息路径](/usr/local/lib/node_modules/@earendil-works/pi-coding-agent/dist/core/agent-session.js:1569)可进入 input；[扩展 runner](/usr/local/lib/node_modules/@earendil-works/pi-coding-agent/dist/core/extensions/runner.js:1096)可串联修改文本，且抛异常后继续。slash 又先于 input，扩展也可触发，故必须验证真实来源，不能仅检查命令名称。
- [OpenAI 兼容实现](/usr/local/lib/node_modules/@earendil-works/pi-coding-agent/node_modules/@earendil-works/pi-ai/dist/api/openai-completions.js:192)已设置 maxRetries 为 0；[协议层重试](/usr/local/lib/node_modules/@earendil-works/pi-coding-agent/node_modules/@earendil-works/pi-ai/dist/utils/provider-retry.js:75)默认也为 0，且支持自定义 fetch。会话级重试和压缩仍需逐次验证。

这些是当前安装版本的源码事实，不是已完成的 Pi 交互或预算验收。

### 3.3 官方服务边界

- [Token 用量说明](https://api-docs.deepseek.com/quick_start/token_usage/)不足以证明当前模型完整请求的 UTF-8 字节上界；[视觉文档](https://api-docs.deepseek.com/guides/vision/)另有图像计费规则，短引用不能代表图片 token。
- [Search／Fetch](https://api-docs.deepseek.com/guides/search/)由服务端获取页面。本地取消或断线不能证明服务端没有成功处理，unknown 预留仍有必要。
- [余额接口](https://api-docs.deepseek.com/api/get-user-balance/)列账户充值／赠送余额；它没有本包自然月预算字段。用户已决定不据此替换本地准入。
- 审查用 4000 输入＋300 输出、2／8 元每百万 token 估算，单轮为 0.0104 元，10 元约 961 轮；尚未含其他推理、工具、检索或重试。这只能说明一个样例量级，不能证明真实学习流程不会触顶。费率来源：[中文价格页](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。

## 4. 验证边界

三源范围更新后的验收区分“成功转换入库”“原件缺材料但候选已入库待处理”和“识别／分题失败尚未转换”。最后一种只保留原页或附件不能算转换完成；全量处理、候选归属与抽样质量分别报告。三份来源均须经过选择、抽题、必要题图查看及备份恢复验证。当前估算随扩围更新为 MVP 41—62 有效工程小时，需要并行；完整首版后续 33—52 小时，不重复计算已前移的专项转换工作。

独立复审另补齐两项：转换器使用可直接运行的 mjs 入口调用包内编译模块，并安排安装产物转换冒烟测试；最终 HTTP transport 明确禁止自动跟随 307／308，安排无第二次发送的回归测试。这些是补入方案的实现与验证要求，尚未运行。

本轮进行文档一致性、审查覆盖、链接／结构检查，以及题库和安装源码的只读核验；没有运行未来应用的测试。完成后交用户审阅，开发状态仍为未开始。
