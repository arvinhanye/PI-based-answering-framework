## 当前功能与自动验证

- 输入答案即计分，无确认框；非法答案不计分、不请求模型。42 项输入分类测试覆盖字母、多选分隔、前缀、判断、填空、问号及自然提问。
- 撤销保留作废记录，移出统计并重建复习安排；数据库 v1→v2 保留历史成绩，允许当前题重答。错题仅在独立答对后清除；辅助答错仍进入错题集。
- 新题按原题号自然排序，来源顺序为 1500→省赛→PDF；4 道复习插 1 道新题；错题轮不插新题。
- 软账本保留旧已结算金额、限额、有效数字费率；旧预留不再占额。返回 usage 幂等入账，多连接/重启、跨月原周期结算、降低费率与零费率均有回归。2050 年仍可按配置费率记账。
- Pi 没有作答工具或离线桩 provider；一层菜单、模型/工具/思考恢复、答对自动下一题、完整轮次结束后重新开始均有回归。
- CLI 使用同一题目/结果卡片，answer 立即显示解析；可选 JSON 供脚本使用。转换、导入、备份原有回归保留。

完整套件：139 项测试 / 23 文件通过（删除的旧网关、预留、菜单确认测试随废弃实现移除）。另通过 typecheck、build、真实 SDK 流程；最终审查后的补充结果见文末。

## 真实图像能力

向内置 `deepseek/deepseek-flash` 发送一张本地题图，最多 128 输出 token。模型准确指出左侧 VLAN 10、右侧 VLAN 20，两个 SSID 均为 Huawei。返回 216 输入、30 输出 token，费用 0.000672 元。通过后才启用生产题图附带路径。图像安全路径、符号链接越界和未发送说明有独立回归。

## 最终独立审查与修复

只读独立审查覆盖本次改造，确认两个需要修复的问题，已逐项复现并完成修复：

1. 原生自动重试费用：将请求归属保留到 `agent_settled`，不再在第一次 `agent_end` 清理。真实 SDK 本地故障 provider 第一次返回 503、第二次成功，修复前账本为 0，修复后准确为 0.00036 元。新增 `probes/ux/retry.mjs`。
2. 外部切题后旧答案误套新题：将操作绑定屏幕已显示的会话和题目；CLI/其他窗口改变状态时，先刷新并提示重新输入。答案、提问、下一题、撤销及两个快捷键均有回归。

同时修正 CLI 题卡的操作提示，明确使用 `study answer A`、`study next`，填空示例加引号。未遗留本轮已确认问题。
