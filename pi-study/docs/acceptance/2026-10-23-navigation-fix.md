# quick 作答与返回导航修复验收

日期：2026-10-23；Pi 0.87.1；macOS。

用户报告普通输入 A 被拦截、各页面缺少返回说明，并把底栏 local-quick 理解为 DeepSeek 未连接。检查确认原输入拦截符合受控学习设计，但原单次菜单操作返回普通输入框、18 项菜单和不明确的 Esc 行为造成操作障碍。

## 修复

- 学习菜单持续显示并分为题目、题库与会话、解析与查证、预算等页面；子页 Esc 返回上一级，输入/确认取消返回所属页面。
- 主菜单退出需确认；模型恢复失败时可以收起菜单，保持离线保护并回到 Pi 输入框。关闭 Pi 不再重新认证原模型；其他生命周期事件仍尝试恢复。
- `/study-answer` 直达答案输入，`/study-exit` 直达退出确认，均不使用命令参数作为答案或授权；拒绝 RPC 写操作并防止菜单重入。
- 提交后显示中文参考判分、作答方式、答案和解析；当前题目菜单优先提供下一题，不再引导重复提交。
- DeepSeek 状态页区分本地宿主、凭证就绪、费率就绪和远程连通；不发付费请求、不展示密钥。
- AI 讲解显示等待与取消入口，取消信号传到实际请求；已发请求费用未知时保留预占。

## 实际验证

- `npm run typecheck`、全量 `npm test`：24 个文件、177 个测试通过；`npm run build` 通过。
- 真实 Pi PTY + 独立临时配置、两道人工样本：进入学习，进入题库子菜单并 Esc 返回；取消答案后返回题目；两次明确确认提交各记一条成绩；显示中文判分并切换下一题；查看状态；收起菜单后普通 A 被拦截且给出操作指引；`/study-exit` 恢复原离线验收模型；`/quit` 正常结束。
- 回归覆盖输入/把握程度/确认三个取消点均不评分、退出恢复失败仍可收起、RPC/命令参数不授权、费率过期/损坏和凭证读取错误、讲解取消后未知预算占额保留。
- 独立检查发现的菜单恢复失败无出口、quit 等待重复认证问题已处理。

## 验证范围

PTY 使用独立测试数据与离线验收 provider，未写入用户真实作答记录。实际 Pi 配置只读确认 DeepSeek 凭证存在、费率当时有效；本轮未新增远程模型请求，状态页也不宣称实时连通。完整首版功能与人工题库准确性验收不因本次导航修复而变为完成。用户已打开的旧 Pi 进程需重启加载新构建。
