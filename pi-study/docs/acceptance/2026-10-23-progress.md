# 路线图 §3.1：进度与成绩验收

2026-10-23。本轮仅本地提交，不推送；比赛日期未设置时不猜测具体日期。

## 已实现

- `/study stats` 和 `/study menu` → 成绩使用同一张文字卡片；不开始新会话、不改变当前题、不调用模型。
- CLI `stats` 使用相同文字布局；`--json` 保留原统计字段并增加来源/考点汇总，来源与考点筛选继续有效。
- 各来源显示去重已做题数和独立正确率；辅助作答单列；错题、到期复习（含逾期）及可选比赛倒计时。
- 只显示已有非占位标签、且至少 5 道独立可计分题目的考点正确率。

## 统计口径

“已做”是有非撤销提交的不同题目数量，包含辅助及不计分题。正确率保持既有口径：独立、辅助分别按每题最新可计分作答统计；原 `covered` 字段仍表示可计分覆盖，新增 `completed` 表示已提交覆盖。历史争议成绩不会因本次显示改造而自动重评。跳过和只有撤销提交的题不算已做。辅助答对不会清除尚未独立答对的错题。
