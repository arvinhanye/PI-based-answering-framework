# Pi 本地 quick 扩展

适配并实测 `@earendil-works/pi-coding-agent` 0.87.1。先 `npm run build`，在独立终端运行：

```sh
PI_OFFLINE=1 pi -ne -ns -np -nc --no-themes -e ./dist/adapters/pi/index.js
```

建议独立 Pi 配置目录，避免加载其他扩展。`-ne` 禁止自动发现，显式 `-e` 仍加载本扩展。本地扩展不是对恶意同进程扩展的隔离沙箱；其他扩展可替换输入、工具或模型。本实现不依赖 source 标签证明真人，不能声称任意扩展组合无冲突。

输入 `/study` 打开持续显示的分级菜单，附带参数全部忽略。`/study-answer` 直接打开当前题目的作答流程，参数同样不作为答案；`/study-exit` 打开退出学习确认。真实 TUI (`mode === 'tui' && hasUI`) 的选择、输入、确认对话框才触发提交、揭晓、跳过或改额。RPC 虽可能有 UI，仍拒绝写操作。学习态普通文本（含被其他扩展转换的文本）全部 handled，不提交、不发模型；失败也 handled。只支持 quick；精学与测验未实现。

主菜单提供“继续刷题”“题库与会话”“解析与查证”“参考成绩”“预算”“DeepSeek 状态”“退出学习”。各子页面明确显示 ↑↓ 选择、Enter 确认、Esc 返回上一级；取消输入或提交会回到所属页面，不会自动计分。题目页选择“提交答案”进入答案输入，确认后显示参考成绩和本地解析，再选择“下一题”继续。题目操作中可以看题图、保存草稿、提示、跳过或揭晓。多选可输入 AC，判断可输入正确/错误，填空使用 | 分隔并保留空格。题库先通过 CLI 导入。提交保留原展示 ID 和修订 ID，防止对话框期间题目变化导致错题提交。子页面 Esc 返回上一级；主菜单 Esc 或“退出学习”打开退出确认，确认后恢复原工具与模型并返回 Pi 对话。若只想回 Pi 输入框，选择“收起菜单（仍在学习态）”，此时普通文本仍被拦截，提示会列出重新作答、菜单和退出命令；可使用 `/quit` 关闭 Pi。模型恢复失败时仍可收起菜单检查配置，不会被菜单循环困住。

进入前必须成功切换专用 `study-offline/local-quick`，然后禁用所有模型工具。该 provider 的 streamSimple 仅返回本地提示，不调用 fetch，无外部 fallback；自动压缩等偶发模型请求在此模型上也只返回本地提示。显式确认的讲解/查证由独立 LearningService 直接调用受预算网关约束的 API，宿主模型始终离线。它不生成学习讲解或有意义的压缩摘要。切走外部模型即结束受控状态、恢复原工具，并明确提示外部路线不受本项目预算保护。退出后的普通宿主聊天也不受本项目预算保护。

仅注册七个只读工具：study_banks、study_session、study_question、study_feedback、study_stats、study_budget、study_pending。题目投影不暴露 assets、来源整页或答案；反馈仅可在已提交/明确揭晓后读取。pending 只给 ID、状态、问题数量，避免原始问题文字泄露答案。未注册提交、揭晓、跳过、改额或原始 SQL/文件工具。

受控 AI 讲解和手动资料查证仅在当前题目已提交或明确揭晓后开放；菜单先验证反馈锁，再确认付费意图，再通过 Pi ModelRegistry.getApiKeyForProvider('deepseek') 解析用户已配置凭证，不写入历史或显示 key。缺少凭证时提示配置方法，本地学习仍可用。仅使用已验证的文本、非流式、关闭 thinking 的限制 profile；生产入口、费率、预占与结算由 LearningService/预算网关检查。流式、任意模型工具、图片生成请求均未开放。预算设置本身不发送付费请求。当前题目以可读文字列出选项、来源、页面以及全部跨页题图的安全绝对路径。“打开题图”仅允许 question 角色的 PNG/JPEG/WebP/GIF，realpath 必须在当前数据空间 assets 内；拒绝目录穿越与符号链接越界。macOS 由实际菜单选择并确认后以 execFile(open, [path]) 打开，其他平台显示路径供手动查看。原始来源整页图不作为题图打开。真实图片 GUI 视觉验收仍需记录。

确认 AI 讲解后会出现“DeepSeek 讲解进行中（最长 60 秒）”和“取消讲解并返回”，Esc 可取消实际请求并返回解析页。确认手动查证后会出现“取消本次查证”菜单；选择该项或按 Esc/Ctrl-C 可取消当前查证。正常完成会自动关闭取消菜单。取消会传递到实际 HTTP 请求；已发送而账单未知的请求保留预算预占，不能因为取消就当作免费。原 30 秒查证超时仍生效，已完成的请求不会被对话框自动关闭误取消。

若原模型凭证不可用，Pi SDK 的 setModel 会返回 false。此时退出会明确报告“原模型恢复失败”，继续保持离线学习态、普通文本拦截和禁用工具；不会声称恢复成功。配置原模型凭证后可重试退出，或显式选择可用的其他模型结束受控状态。关闭 Pi 时直接释放本地资源，不再等待原模型认证；重载或切换会话时仍尝试恢复。

“DeepSeek 状态”只检查 Pi 中凭证能否解析、受控调用模型和费率配置，不发送模型请求、不收费，也不把“已配置”称为“已联网”。学习态底栏的 local-quick 表示本地判题；受控讲解实际使用 deepseek-flash，不跟随普通聊天的默认模型。只有提交或揭晓后，选择讲解/查证并确认费用，才发送远程请求。
